# POWER_BI_PROJECT2
Power BI project showcasing advanced features with slicers, bookmarks, synced visuals, and transaction analysis for 2024.

## 📌 Overview
This project demonstrates advanced Power BI features including slicers, bookmarks, and synced visuals for transaction and balance analysis in 2024.

## 🔧 Steps Taken
- Performed data cleaning (handled nulls and duplicates).
- Profiled the dataset for usage.
- Added 10 slicers with different headings on the first page.
- Created a line chart showing transactions by month for 2024.
- Built a matrix on the second page with the same slicers.
- Synced slicers across both pages.
- Added and updated bookmarks for navigation.


## 📊 Key Visuals
- **Transactions by Month (Line & Column Charts)** — Monthly transaction trends for 2024.
- **Balance by Month (Line & Column Charts)** — Monthly balance trends with interactive filters.
- **Matrix View** — Multi‑city and multi‑currency transaction amounts and balances.
